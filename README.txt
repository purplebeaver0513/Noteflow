PPitch + Noteflow

Extract all files together. Open index.html in your browser. The scripts, styles, fonts, and pitch model are included and require no installation. For microphone access, use an HTTPS website or a local static server if your browser restricts local HTML microphone access. To publish elsewhere, upload all files together and use index.html as the entry point.

This is the existing combined app, with Q/Z keyboard controls and Shift +2 octaves, separated into editable source files. No app behavior was changed. See LICENSES.txt for bundled dependency notices.

The bundled Noteflow.html is the complete portable, single-file app and is also used by the Download app button.
